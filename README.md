# Gym-web-app
Edzőtermi tagság- és edzésnapló alkalmazás  Probléma: Az edzőterembe járók nehezen követik a fejlődésüket.  Funkciók: felhasználói profil, edzéstervek létrehozása, gyakorlatok kezelése, súlyok és ismétlések rögzítése, fejlődési statisztikák.  Adatbázis: felhasználók, edzések, gyakorlatok, eredmények.

# A KKK elvárásainak kijegyzetelése
A KKK elvárásainak kijegyzetelése
A szoftverrel szembeni elvárások
Valódi problémára adjon megoldást: A projekt egy olyan problémát oldjon meg, amely a mindennapi életben vagy egy vállalkozásnál is előfordulhat.
Adatkezelés és adattárolás: A program adatbázist használjon, amelyben az adatokat el tudja menteni, módosítani, törölni és lekérdezni.
RESTful architektúra: A rendszer két részből álljon:
Szerveroldali (backend) alkalmazás, amely kezeli az adatokat és biztosítja az API-t.
Kliensoldali (frontend) alkalmazás, amely a felhasználó számára biztosítja a kezelőfelületet.
Több eszköz támogatása: A kliensalkalmazás legyen használható számítógépen és mobil eszközön is.
Tiszta forráskód: A program a Clean Code alapelveit kövesse, vagyis legyen jól áttekinthető, megfelelően tagolt, könnyen olvasható és karbantartható.
Dokumentáció: A projekthez részletes dokumentáció készüljön, amely bemutatja a működést, a felépítést és a használatot.
A leadandó csomag tartalma
Forráskód: A projekt teljes kliens- és szerveroldali forráskódja.
Adatbázismodell-diagram: Az adatbázis tábláinak és kapcsolatainak ábrázolása.
Adatbázis dump: Az adatbázis exportált állapota, amelyből az adatbázis újra létrehozható.
Dokumentáció: A projekt leírása, a technológiák bemutatása, a telepítés és a használat ismertetése.
Tesztkód: A program működését ellenőrző automatikus tesztek.
Teszteredmények: A tesztek futtatásának eredményei, amelyek igazolják a rendszer megfelelő működését.
